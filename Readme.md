# Sistema de Gerenciamento de E-commerce

Sistema de gerenciamento de uma loja de e-commerce de tecnologia, desenvolvido como projeto da turma Back-end 5.

Autor: Casiano Fabio Hoto
Turma: Back-end 5

---

## Sobre o projeto

O objetivo é fazer o gerenciamento de uma loja de e-commerce de tecnologia, controlando produtos, clientes, carrinho de compras e pedidos.

## Funcionalidades

- Cadastrar e gerenciar produtos
- Cadastrar e consultar clientes
- Gerenciar o carrinho de compras
- Finalizar os pedidos

## Tecnologias utilizadas

- TypeScript e JavaScript
- Métodos de array: `find()`, `filter()`, `map()`, `reduce()`
- Compilação com 'TSC'
- Execução com 'Node.js'

## Regras de negócio

- Cadastrar um produto no estoque
- Buscar um produto em estoque
- Consultar cliente
- Não aceitar nomes de clientes com menos de três letras
- Não cadastrar produtos fora da categoria
- Não cadastrar produto com valor negativo
- Não recebe pagamento

## Limitações

- Tamanho limitado
- Não possui banco de dados
